# Código Fuente y Simulaciones Reproducibles (`src/`) / Source Code & Reproducible Simulations (ES / EN)

Esta carpeta aloja las implementaciones ejecutables en Python vinculadas a las especificaciones formales del **Corpus IGLV**.

This folder hosts the executable Python implementations linked to the formal specifications of the **IGLV Corpus**.

## Módulos / Modules

1. **`mi_star_sat_v0_3.py`** — Solver SAT educativo con análisis estructural incremental (grafos de dependencia + componentes fuertemente conexas de Tarjan). · [`DOI: 10.5281/zenodo.23881112`](https://doi.org)
2. **`operium_motor_v5.py`** — Simulación de la Cascada de Extracción ($P_1 \to P_n$) desde campo continuo $C_1$ con reconfiguración `_metacierre`. · [`DOI: 10.5281/zenodo.24302409`](https://doi.org)
3. **`maquina_persistencia.py`** — Implementación de *Cyber-synekia* (Radar del Convenio, Búnker Normativo y Semáforo de Ruptura). · [`DOI: 10.5281/zenodo.23853133`](https://doi.org)
4. **`ignicion_ejes_v5_v7.py`** — Verificación de invariantes, estrés $20\times$ y calibración de ejes $(\sigma, \tau)$ en malla $6 \times 6$. · [`DOI: 10.5281/zenodo.23852880`](https://doi.org)

## Requisitos / Requirements
* Python 3.10+ (biblioteca estándar; sin dependencias externas pesadas).
