# Código Fuente y Simulaciones Reproducibles (`src/`) / Source Code & Reproducible Simulations (ES / EN)

Esta carpeta aloja las implementaciones ejecutables en Python vinculadas a las especificaciones formales del **Corpus IGLV** (puedes consultar el código completo en los archivos referenciados en los DOI correspondientes):

1. **[`operium_cascada.py`](./operium_cascada.py)** — *El Operium y la Cascada de Extracción* (confrontación de impactos $C_1$, presión operativa y mutación estructural `_metacierre`): [`DOI: 10.5281/zenodo.24302409`](https://doi.org)
2. **[`motor_ignicion_v5.py`](./motor_ignicion_v5.py)** — *Especificación Formal del Motor Ignición v5* (simulación estocástica Monte Carlo de viabilidad acotada): [`DOI: 10.5281/zenodo.23911868`](https://doi.org)
3. **[`cyber_synekia_normativa.py`](./cyber_synekia_normativa.py)** — *Cyber-Synekia* (verificación topológica BFS del Convenio): [`DOI: 10.5281/zenodo.23853133`](https://doi.org)
4. **[`mi_star_sat_v0_3.py`](./mi_star_sat_v0_3.py)** — *MI\*-SAT v0.3* (solver SAT educativo con análisis estructural incremental): [`DOI: 10.5281/zenodo.23881112`](https://doi.org)

## Requisitos / Requirements
* Python 3.10+ (`numpy` para `operium_cascada.py` y `motor_ignicion_v5.py`; biblioteca estándar pura para `cyber_synekia_normativa.py` y `mi_star_sat_v0_3.py`).
